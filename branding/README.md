# ADDER branding

`adder-brand-board-placeholder.jpg` is the user-supplied temporary brand board. It contains the proposed mascot, wordmark, wide logo, and avatar treatments in a single image.

It is not a production-ready asset pack. Before release, replace it with approved isolated files:

- `adder-wide-logo.png` for repository and documentation headers
- `adder-avatar.png` for GitLab project and bot avatars
- `adder-mascot.png` for standalone illustration use
- `adder-wordmark.png` for text-forward layouts

Document approved colors, typography, clear space, minimum sizes, accessibility alternatives, ownership, and permitted use when final assets are supplied. Do not remove the word “placeholder” from references to the current board.

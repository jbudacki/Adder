# ADDER policies

The repository contains advisory pilot policies:

- `core-decision-policy.md` defines block-recommended, manual-review, warning, pass, exception, and degraded-operation rules.
- `package-trust-policy.md` defines attributable package identity, source, artifact, and intelligence evidence.
- `security-test-evidence-policy.md` defines behavior-level security test requirements and sufficiency decisions.
- `control-promotion-policy.md` defines candidate, advisory, mandatory, rejected, and retired control states with human approval gates.

Policy owners and exception authorities remain unresolved, so these files are not enterprise enforcement policies.

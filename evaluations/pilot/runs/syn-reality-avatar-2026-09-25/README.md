# Syn Reality Avatar operational pilot

This directory contains one read-only operational ADDER assessment of a user-supplied AI/RAG application source snapshot.

- `operational-pilot-report.md` — primary human-readable report
- `assessment.json` — normalized ADDER assessment
- `adder-report.md` — generated GitLab advisory report
- `gl-code-quality-report.json` — generated GitLab Code Quality annotations
- `risk-classification.json` — Tier 3 rationale
- `provenance.json` — unverifiable snapshot provenance record
- `test-evidence-assessment.json` — security-test evidence gaps
- `threat-model.md` — split STRIDE and MAESTRO model
- `pilot-observations.json` and `pilot-summary.json` — measured and unavailable pilot metrics

No target files, services, external APIs, registries, credentials, cloud accounts, or production systems were modified or exercised.

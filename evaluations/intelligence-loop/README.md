# Intelligence-loop evaluations

These fixtures verify that lessons become governed control candidates without autonomous promotion. They cover repeated findings, single-repository evidence, false positives, incomplete release evidence, remediation learning, and contradictory evidence.

`control-candidates.json` contains candidate records derived from the operational pilot. They remain candidates because human validation, ownership, broader cohort evidence, and complete fixtures are missing.

Run:

```sh
python3 scripts/validate_phase6.py
```
